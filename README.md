# 旅策 · 把计划装进口袋

手机优先的旅行规划工具，源自中文手机端原型。浅色森林绿界面，无需安装 App 即可体验。

## 已实现

- 多份旅行计划：日期、同行人、人均预算与偏好；杭州、成都、大理提供本地灵感模板，其他城市从空白创建。
- 问 AI：规划与灵感统一页面，多轮补齐条件、查询真实候选、生成 1–7 天草稿；旅行中调整选定的一天，预览确认后应用，保留其他日期与账单。新版对话接口已在腾讯云升级并实测。
- 每日行程：添加、编辑、删除地点，上下排序，预计费用与停留时间。
- 行程地图：真实高德点位，全程/当天范围、每日颜色和顺序标记、道路线路、时间与交通合理性校验；缺少数据时标记待核实。
- 美食·住宿：分类搜索城市或已确认行程地点附近的高德 POI；大众点评、同程、携程数据待接入，只提供明确的官网入口。
- 旅行账本：消费增删改、付款人与参与人、按整数分均摊、尾差处理、转账结算建议。
- 出发清单：分类、增删、勾选、进度与预设去重。
- 我的：切换旅行、修改名称与预算、食宿收藏、JSON 备份与追加导入、当前日程打印。
- 只读快照链接：仅含地点、时间、类型与停留时间，不含成员姓名、私人备注与账单。
- 本机自动保存；存储失败提示并保留导出入口。

## 运行与检查

需要 Node.js 22.13 或以上（测试使用内置 SQLite），不需要安装 npm 依赖。

```sh
npm run dev
# 打开 http://localhost:3000
npm test
npm run build
```

源码直接位于 `dist/`，可部署到任何静态托管平台。`scripts/serve.mjs` 仅供本地开发；部署时使用正式静态托管。

## GitHub Pages 部署

仓库内已配置 `.github/workflows/pages.yml`：推送至 `main` 后，自动运行测试、检查静态资源，并只发布 `dist/`，不会发布源码、测试或托管配置。

首次启用：仓库 **Settings → Pages → Build and deployment → Source → GitHub Actions**。之后到 **Actions → Deploy GitHub Pages → Run workflow** 发起第一次部署；后续推送会自动更新。最终访问地址以该工作流的 `github-pages` environment 链接为准。

GitHub Free 需要公开仓库才能使用 Pages；私有仓库需要支持该功能的付费计划。Pages 网站公开访问，不要求登录 ChatGPT。不同域名的浏览器存储互不相通，从其他体验地址迁移时，可先导出 JSON 备份再在新地址导入。

## 数据说明

数据保存在当前浏览器的 `localStorage`，不上传账单，不自动跨设备同步。初始杭州行程与消费为可修改的示例。新建旅行不会继承示例账单。

完整备份包含同行人和消费明细，请妥善保管。导入前校验格式与成员关联，只追加尚不存在的旅行，不覆盖同 ID 的本机内容。

分享内容打包在 URL fragment 中，是生成时的快照。修改原计划不会同步，已分享快照无法远程撤回；接收者需要具有托管站点访问权限。不要在公开地点名称中填写隐私信息。

普通新建旅行可使用本地模板；「问 AI」调用统一的 DeepSeek 服务。两者都不提供实时天气、票价、营业时间与精确交通时长。行程预计费用不会自动计入实际消费，出发前请自行核实。

## AI 服务接入状态

原有 AI 行程生成已接入腾讯云独立后端 `https://kuaitrip.cn/lvce-ai`。新版页面统一沟通和规划，既可另存新旅行，也可预览后调整当天。`/api/chat` 已部署，真实对话地点查询与当天调整草稿生成已验证；旧服务仍兼容条件草稿生成。已验证公网 HTTPS、跨域预检和真实 DeepSeek 单日行程生成。原有手动规划和模板功能不受影响。

`dist/ai-api.js` 中的 `AI_BASE` 只能配置已验证的 HTTPS 后端基础地址，不得包含 API Key。普通用户不填写密钥，后端通过固定 DeepSeek 地址调用模型。API Key 不应提交到 GitHub，也不应放进前端、备份或分享链接。

对话发送本次消息、必要历史和出行条件；调整时附带当天地点名称、时间、类型、停留与预计费用。成员姓名、账单、已有私人备注及精确定位不发送。请勿在消息中填写敏感信息。调整会检查当天签名，避免覆盖生成期间的编辑；账单、其他天和清单保留。

独立部署入口位于 `backend/tencent/`，复用 `backend/worker/` 的生成校验和配额逻辑；开放状态、生成、对话与地图接口，不开放旧身份管理页。不要将后端目录部署到 GitHub Pages；前端发布工作流只上传 `dist/`。实际 AI 生成需保持后端在线且 DeepSeek Key 有效、有余额。自动化测试使用固定响应，不消耗实际模型用量。

## 后续开发

官方点评/预订平台数据、天气、登录与跨设备同步可在后续迭代接入。接口密钥应放服务端，不应写入前端或仓库。

### 腾讯云独立 AI 后端

现已提供 Ubuntu + Docker + 现有 Nginx 的部署版本，见 [部署说明](backend/tencent/README.md)。服务使用服务器环境变量保管 DeepSeek Key，根据用户明确选择，生产 AI 生成与对话不设每日/每小时次数上限，保留 SQLite 重复请求防护；实际用量由 DeepSeek 账户计费。地图限额独立。通过独立 `/lvce-ai/` 路径接入现有 HTTPS 网站，不依赖 Sites 登录。部署脚本会备份现有配置；前端已配置经过验证的腾讯云后端地址。

### 高德地图与产品需求

持续维护的 [PRD](docs/PRD.md) 已记录地图接入与首页 AI 对话推荐流程，以及各阶段验收状态。本轮新增真实地图、城市/周边 POI 搜索、用户确认地点和步行/驾车路线查询；需在腾讯云运行 [地图配置工具](backend/tencent/configure-maps.py) 后才能使用真实服务，不能把代码完成当作已经验证上线。具体操作见 [服务器部署说明](backend/tencent/README.md)。旧行程的文字地点需手动匹配，前端不把示意图冒充真实路线。
