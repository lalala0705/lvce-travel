## 产品与用户

面向手机用户，把旅行灵感、出行计划、地点导航、准备清单和共同费用串起来。既支持已有目的地的人，也支持“附近想玩水”“周末想徒步”但没有明确目的地的人。用户无需填写模型或地图密钥。

## 当前能力

- 手动创建多个旅行，按日增删、编辑、排序地点；本机自动保存、备份和导入。
- 按实际参与人分摊消费，整数分计算尾差与转账建议；行程预计费用不自动入账。
- 分类清单、收藏、打印；分享快照排除成员姓名、私人备注、账单和定位数据。
- DeepSeek 根据目的地、日期、人数、预算、节奏、偏好和补充要求生成 1–7 天草稿，校验后预览，另存为新旅行，不覆盖已有账单。
- 无账户同步；本机数据不会因服务器部署自动迁移。

## 本轮：高德地图基础

状态：代码与部署工具已完成，自动化与手机页面流程测试通过；真实服务须服务器配置并通过线上验证。

### 地图与地点

1. 「地图」页按需加载高德 JS API 2.0，保留高德地图标识；地图未配置或加载失败时显示真实状态和外部地图入口。
2. 搜索城市和关键词（例如公园、亲水景区、徒步步道），展示最多 10 个高德候选地点及地址，由用户选择具体 POI。
3. 选中后进入地点编辑，用户确认时间、停留时长和费用后保存。记录 POI 标识、地址、来源、GCJ-02 坐标；更改地点名时移除旧坐标匹配，避免错位。
4. 旧模板和 AI 文字地点不自动冒充已核实 POI，提供「在地图上确认」入口；地图仅展示用户已匹配的真实点位。
5. 相邻已匹配地点可分别查询步行或驾车路线，显示距离、可用时长和高德道路折线。无路线时不以直线假装道路，不自动为全部行程产生查询。
6. 首页增加「找游玩灵感」入口，先承接真实地点搜索；它不是已经完成的多轮 AI 对话。

### 定位和安全边界

- 默认城市搜索，不请求定位。点击「使用当前位置」前说明用途与接收方，浏览器询问授权；拒绝、超时或不支持时仍可手动输入城市。
- 使用浏览器 WGS-84 定位时先通过高德转换，再进行周边搜索，避免与 GCJ-02 地图混用。
- 定位只在本次搜索内使用，不写入账单、本机备份或分享；后端不记录搜索文字、精确坐标或请求正文。
- 距离区分周边直线距离与道路查询距离；车程仅为本次查询参考，不承诺未来时段交通。
- 高德 POI 存在不等于实时开放或活动安全：不凭水域地点判定可游泳，不凭步行道路判断山野轨迹、封山、天气或涉水风险。

### 接入与凭证

- 网页 JS Key 用于加载 SDK，可以在网络请求中公开；限制允许的网站域名。
- JS 安全密钥和 Web 服务 Key 只保存在腾讯云服务器环境文件；前端不填写、不存储、不接收这两个值。
- JS 安全密钥通过固定白名单路径代理注入，不提供任意 URL 转发。
- 地点和路线走统一后端，限定 Origin、参数、返回体、超时与配额；独立于 AI 20 次/天、3 次/IP/小时的额度。
- REST 地图试用保护：全站 1000 次/天、每个 IP 60 次/小时；SDK 代理单独限制 2000 次/天、300 次/IP/小时。一次带定位搜索可能包含坐标转换和地点查询两次服务调用。
- 不自动开通付费套餐、购买地图许可或假设免费额度；实际权限及计费以管理员高德账户为准。

### 验收

- 有效凭证与白名单下，GitHub Pages 页面展示真实地图，地点来源为高德。
- 城市及关键词搜索可用；定位授权后周边查询可用；拒绝定位可继续城市搜索。
- 选中地点、编辑、保存、刷新和备份导入后，POI 匹配一致；改名移除旧匹配。
- 步行/驾车路线显示真实距离和高德折线，无匹配坐标时不查询路线。
- 密钥错误、权限不足、断网、零结果和限额错误均有可理解的反馈，原有行程与账单保留。
- 响应、前端源码及分享快照不包含服务密钥或 JS 安全密钥。

### 流程

首页一句话输入框与快捷主题（附近玩水、轻松徒步、带娃半日游、周末没想好去哪）→ AI 每次只追问 1–2 项必要条件 → 高德搜索真实候选 → 展示 3 个地点并说明适配理由与未知信息 → 用户选择 → 补齐日期、同行、预算与交通 → 生成可预览行程 → 保存并继续编辑。

对话需逐步明确：出发城市或自愿授权的位置、可接受范围/车程、时间、同行人与体力约束、交通方式、预算与偏好。避免一次性长表单，也不在用户已给信息后重复询问。

推荐理由必须区分高德查询事实、用户条件与模型建议。候选地点不可由模型编造；车程约束需真实路线查询支持，超时或查询失败时明确无法核实，不将半径等同于车程。游泳许可、水情、户外轨迹、开放规则和天气不能凭 POI 数据断言。

模型调用、地点调用分别可取消、限流，不自动无限重试；新一轮对话的模型额度策略需在实施时明确并保留全站费用保护。生成前展示已归纳条件，先预览再保存。
